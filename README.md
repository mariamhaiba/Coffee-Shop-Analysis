☕ Coffee Shop Sales Analysis Dashboard

📌 Project Overview

This project analyzes coffee shop sales data using Microsoft Excel to explore revenue performance, product sales, store performance, and transaction patterns.

🎯 Project Objectives

- Track key sales performance indicators.
- Analyze monthly revenue trends.
- Compare revenue across store locations.
- Identify the top 5 products by revenue.
- Explore transaction patterns by hour and day of the week.
- Compare revenue across product categories.

🛠️ Tools & Skills

- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Interactive Slicers
- Data Analysis
- Dashboard Design

📊 Key Performance Indicators (KPIs)

- Total Revenue
- Total Transactions
- Units Sold
- Average Revenue per Transaction

📈 Dashboard Features

- Monthly Revenue Trend
- Revenue by Store Location
- Revenue by Product Category
- Top 5 Products by Revenue
- Transactions by Hour
- Transactions by Day of the Week
- Interactive filters for Month, Product Category, and Store Location

🧮 Calculation

Revenue = Unit Price × Transaction Quantity
